## 📋 معرفی

سامانه جامع مدیریت درمانگاه **سهند** برای محیط کسب‌وکار ایران طراحی شده: از پذیرش و نوبت‌دهی هوشمند تا پرونده بالینی پیشرفته با نمودار رشد WHO، از صندوق و حسابداری دوبل تا فیش حقوقی با قواعد ۱۴۰۴، و از اتصال به **دستگاه‌های حضور و غیاب ZKTeco و Hikvision** تا نظرسنجی پیامکی بیماران و **پشتیبانی زنده یکپارچه**.

| شاخص | مقدار |
|:---|:---|
| 🧱 لایه‌های معماری | Clean Architecture + CQRS + Repository/UnitOfWork |
| 📦 پروژه‌های .NET | ۸ پروژه (Domain/Application/Infrastructure/API/Desktop/LicensePortal/Shared) + سرور لایسنس PHP |
| 🗄 جداول دیتابیس | ۹۷+ جدول (۹۴ پایه + آرشیو + قالب چاپ + لیست انتظار و…) + ۱۵ ایندکس حضور و غیاب |
| 🔌 API | ۲۵ کنترلر — ۳۰۰+ endpoint |
| 🖥 فرم‌های دسکتاپ | **۶۴ فرم WPF** با Material Design و RTL کامل |
| 🧪 تست‌های خودکار | **۲۵۰ تست دات‌نت** در ۵ پروژه + ۳۴ تست E2E لایسنس — بیلد سورس بدون هشدار |
| 🧩 ماژول‌های لایسنس | **۳۹ ماژول** قابل فعال‌سازی جداگانه |
| 📈 گزارش‌های نموداری | **۲۵ گزارش** با نوع درست نمودار برای هر ماهیت (سطحی/ستونی/دونات/میله‌ای) + گزارش‌ساز رایگانه بدون SQL |
| 📨 پیام پشتیبانی | ارسال مستقیم پیام از پنل لایسنس روی داشبورد درمانگاه (۴ سطح اهمیت) |
| 🪪 ضدجعل | اعتبارسنجی الگوریتمی کد ملی بیماران در ثبت و ویرایش |
| 💼 حقوق درصدی پرسنل | درصدی از **سود خدمات انجامی خود پرسنل** (نه کل فروش) با عکس‌فوری هزینه در لحظه صدور فاکتور |
| 🌐 زبان | فارسی کامل — تقویم جلالی، رقم فارسی، RTL |

## 🆕 جدید در نسخه ۲.۰.۰ — ۱۶ قابلیت در ۶ محور

اجرای کامل ۱۶ قابلیت انتخاب‌شده مالک از سند [FEATURE-IDEAS.md](docs/FEATURE-IDEAS.md):

| محور | قابلیت‌ها |
|:---|:---|
| 🩺 **بالینی (۴)** | موتور ۷بُعدی ایمنی دارویی (۵۲۳ جفت تداخل + بارداری FDA + حساسیت متقاطع ATC + Beers سنی + کلیوی/کبدی + گیت منع با دلیل کتبی) • نوار نتایج غیرعادی پاراکلینیک روی پرونده (H/HH/L/LL) • خط زمان ۷ نوع رویداد پرونده با برچسب شمسی • طراح قالب چاپ سفارشی ۹ نوع سند با ویرایشگر HTML و پیش‌نمایش زنده |
| 💰 **مالی (۲)** | تسویه حساب بیمه با موتور قواعد ۴سطحی (درصدی/اسمی/فرانشیز/سقف) و صورتحساب طبقه‌بندی‌شده • صندوق روزانه و بستن شیفت با شمارش فیزیکی، اختلاف‌سنجی رنگی و رسید چاپی SHR |
| ⏳ **نوبت‌دهی (۱)** | لیست انتظار هوشمند — با لغو نوبت، خودکار پیامک پیشنهاد جای خالی به متناظرترین منتظر همان پزشک |
| 📈 **هوش تجاری (۶)** | رشد MoM + مقایسه YoY (مجموع ۲۵ گزارش نموداری) • داشبورد شخصی‌سازی‌شده هر کاربر • گزارش‌ساز رایگانه گرافیکی بدون SQL (لیست سفید ۷ موجودیت ~۹۰ فیلد) • تحلیل RFM رده ۸گانه با پیامک هدفمند • پیش‌بینی روند درآمد با بازه اطمینان ۸۰٪ • خروجی PDF همه گزارش‌ها با سربرگ درمانگاه و فونت جاسازی‌شده |
| 🔧 **زیرساخت (۲)** | بکاپ ابری S3-سازگار (آروان/ابستور) با رمزنگاری AES-256-GCM و بارگذاری شبانه • آرشیو سالانه با جابه‌جایی محافظت‌شده ۷ جدولی و مرورگر پرونده قدیمی — بانک عملیاتی همیشه سبک |
| 🎓 **آموزش (۱)** | تور هدایت‌شده ۸ ایستگاهی اولین اجرا با هایلایت نقطه‌ای + مرکز آموزش با ۱۰ درس تعاملی گام‌به‌گام و پیشرفت یادگیری هر کاربر روی سرور |

## 🗒 گزارش نسخه ۱.۹.۰ (پیشین)

| قابلیت | شرح |
|:---|:---|
| 🔐 **سامانه لایسنس PHP حرفه‌ای** | اطلاعات کامل درمانگاه (مدیر/ایمیل/شهر/نشانی) + ویرایش کامل لایسنس + حذف امن دومرحله‌ای + داشبورد نموداری ۴گانه SVG + صفحه گزارش‌های ۵گانه با خروجی CSV + انیمیشن‌های فراوان (شمارنده، حلقه پیشرفت، ترسیم خط، قطاع پلکانی) |

| 📈 **۲۱ گزارش نموداری** | دو دسته جدید در گزارش‌ساز: روند درآمد/بیمار جدید/نسخه (سطحی)، مقایسه ماهانه/شعبه/سن بدهی (ستونی)، سهم پزشکان/بیمه/پرداخت/جنسیت/وضعیت نوبت/حقوق درصدی (دونات)، رتبه‌بندی خدمات/بدهکاران/آزمون/دارو (میله‌ای افقی) |
| 🛡 **سه گام امنیتی** | نگهبان کلید JWT در تولید (کلید ضعیف = بالا نیامدن سرور) + پشتیبان‌گیری خودکار شبانه ۲ بامداد با پاک‌سازی نسخه‌های قدیمی + ممیزی کامل ۱۹۱ endpoint (۱۸ مورد حساس پوشش داده شد) |
| 🧪 **تست دسکتاپ متولد شد** | پروژه تست ViewModel با کلاینت ساختگی + ۶ تست جریان‌های پول‌ساز — کل مجموعه **۱۷۲ دات‌نت + ۳۴ E2E** سبز |
| ⚡ **بهبودهای سریع** | سینک Seq شرطی، openapi.json خودکار (۱۷۷ مسیر) هنگام بیلد، کش یک‌ساعته کاتالوگ گزارش‌ها، مستند کامل ۴ جاب پس‌زمینه |
| 🎨 **بنرها و پوسترهای مدرن** | بازطراحی کامل ۴ فایل با عمق لایه‌ای واقعی (کارت‌های شیشه‌ای شناور، بدون کج‌کردن تصویر داشبورد) |
| 💡 **سند قابلیت‌های پیشنهادی** | `docs/FEATURE-IDEAS.md` — ۴۳ پیشنهاد در ۸ محور برای انتخاب و اولویت‌بندی مالک |

## 🚀 راه‌اندازی سریع

### نصب درمانگاهی از GitHub Release

1. روی رایانهٔ مرکزی SQL Server را نصب و اجرا کنید.
2. فایل `SahandClinicPro-Server-v2.23.1.zip` را از [صفحهٔ Releases](https://github.com/pranses2011/Sahand_ClinicPro/releases/latest) دانلود، استخراج و `Install-Server-Package.bat` را با دسترسی مدیر اجرا کنید. رشته اتصال SQL را وارد کنید؛ ساخت دیتابیس و اعمال خودکار schema در همین فرایند انجام می‌شود و migration دستی لازم نیست.
3. فایل `SahandClinicPro-Setup-v2.23.1.exe` را روی رایانه‌های کاربران نصب کنید. این نصب‌کننده خودبسنده است و نیاز به نصب جداگانهٔ .NET ندارد.
4. برای کلاینت‌های غیر از رایانهٔ سرور، `ApiSettings:BaseUrl` در فایل `appsettings.json` کنار برنامه را به `http://IP-سرور:5000/api/v1` تغییر دهید.

بررسی آمادگی کامل سرور و اتصال دیتابیس: `http://localhost:5000/health/ready` باید `Healthy` نشان دهد. جزئیات در [`راهنمای نصب`](docs/guides/deployment.md) آمده است.
