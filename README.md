## 📋 معرفی

سامانه جامع مدیریت درمانگاه **سهند** برای محیط کسب‌وکار ایران طراحی شده: از پذیرش و نوبت‌دهی هوشمند تا پرونده بالینی پیشرفته با نمودار رشد WHO، از صندوق و حسابداری دوبل تا فیش حقوقی با قواعد ۱۴۰۴، و از اتصال به **دستگاه‌های حضور و غیاب ZKTeco و Hikvision** تا نظرسنجی پیامکی بیماران و **پشتیبانی زنده یکپارچه**.

| شاخص | مقدار |
|:---|:---|
| 🧱 لایه‌های معماری | Clean Architecture + CQRS + Repository/UnitOfWork |
| 📦 پروژه‌های .NET | ۸ پروژه (Domain/Application/Infrastructure/API/Desktop/LicensePortal/Shared) + سرور لایسنس PHP |
| 🗄 جداول دیتابیس | ۹۴ جدول + ۱۵ ایندکس حضور و غیاب + جدول اقلام انبارگردانی |
| 🔌 API | ۲۵ کنترلر — ۳۰۰+ endpoint |
| 🖥 فرم‌های دسکتاپ | **۵۲ فرم WPF** با Material Design و RTL کامل |
| 🧪 تست‌های خودکار | **۱۴۳ تست سبز** در ۴ پروژه — بیلد بدون هیچ هشدار |
| 🧩 ماژول‌های لایسنس | **۳۰ ماژول** قابل فعال‌سازی جداگانه |
| 🪪 ضدجعل | اعتبارسنجی الگوریتمی کد ملی بیماران در ثبت و ویرایش |
| 💼 حقوق درصدی پرسنل | درصدی از **سود خدمات انجامی خود پرسنل** (نه کل فروش) با عکس‌فوری هزینه در لحظه صدور فاکتور |
| 🌐 زبان | فارسی کامل — تقویم جلالی، رقم فارسی، RTL |

## 🆕 جدید در نسخه ۱.۷.۰

| قابلیت | شرح |
|:---|:---|
| 💼 **حقوق درصدی پرسنل از سود خدمات** | در تعریف پرسنل علاوه بر حقوق پایه، «درصدی از سود خدمات انجامی خودِ همان پرسنل» لحاظ می‌شود — نه از کل فروش و نه از کل دریافتی درمانگاه. سود هر قلم فاکتور = مبلغ نهایی − (هزینه عکس‌فوری × تعداد)؛ عکس‌فوری هزینه در لحظه صدور ثبت می‌شود تا تغییر آتی هزینه، سوابق و فیش‌های گذشته را خراب نکند |
| 🧾 **فیش حقوقی شفاف** | سه ستون جدید در فیش: درصد، مبنای سود خدمات دوره و مبلغ حقوق درصدی + ردیف چاپی «حقوق درصدی از سود خدمات (X٪)» با یادداشت مبنای محاسبه |
| 🏷 **انتخاب پرسنل انجام‌دهنده در فاکتور** | ستون «انجام‌دهنده» در اقلام فاکتور — هر خدمت به پرسنل انجام‌دهنده منتسب می‌شود و سود همان اقلام در فیش او لحاظ می‌شود |
| 🎨 **آیکون رسمی محصول** | ClinicPro.png به آیکون شش‌مقیاسی ویندوزی تبدیل شد — روی فایل exe، Taskbar و نوار عنوان هر ۵۲+ پنجره + فایل SetupIconFile نصب‌کننده (که قبلاً غایب بود و کامپایل Inno Setup را می‌شکست) |
| 📸 **رفع باگ فونت اسکرین‌شات‌ها** | ریشه‌یابی کامل: مسیر @font-face غلط بود و وزیرمتن هرگز بارگذاری نمی‌شد — اصلاح مسیر + سازوکار «بار دوم» + راستی‌آزمایی خودکار فونت + لوگوی رسمی در نوار کناری؛ هر ۵۲ اسکرین‌شات و بروشور بازتولید شد |
| ✅ **۶ تست جدید** | پوشش کامل منطق حقوق درصدی: درصد از سود نه کل فروش + سود منفی→صفر + جزء مزایای مشمول بیمه/مالیات + گرد شدن ریالی — کل مجموعه ۱۴۳/۱۴۳ سبز |

## 🧩 ماژول‌ها و امکانات

### 🕐 ماژول حضور و غیاب

اتصال مستقیم به دستگاه‌های حضور و غیاب با درایورهای اختصاصی:

| قابلیت | شرح |
|:---|:---|
| 🔌 درایور ZKTeco | پروتکل PULL روی TCP/4370 — وفادار به مرجع pyzk (هدر ۴×u16، چک‌سام zkemsdk، رکورد ۴۰ بایتی) |
| 🌐 درایور Hikvision | ISAPI با احراز Digest — سریال و گزارش حوادث |
| 💫 شبیه‌ساز دمو | تولید ضربه منطقی برای آموزش و تست |
| ⚙ همگام‌سازی خودکار | کار Hangfire هر دقیقه با بازه اختصاصی هر دستگاه + حذف تکراری |
| 📜 لاگ خام تغییرناپذیر | منبع حقیقت ممیزی — هیچ ضربه‌ای حذف نمی‌شود |
| 👥 نگاشت کاربر دستگاه | هر شناسه کارت/اثر انگشت → پرسنل |
| ⏰ شیفت‌های پیشرفته | تحمل تأخیر/تعجیل، استراحت، شیفت شب عبور از نیمه‌شب، شبانه‌روزی ۲۴ ساعته |
| 🗓 تخصیص الگودار | ثابت / هفتگی / روزهای منتخب + اولویت‌بندی تعارض |
| 🏖 مرخصی و تعطیلات | پوشش مرخصی/مأموریت تأییدشده + تقویم تعطیلات رسمی و تکرارشونده |
| 📝 اصلاح کارت | جریان درخواست → تأیید سرپرست → اعمال خودکار با پرچم ممیزی |
| 📊 گزارش ماهانه شمسی | کارکرد/تأخیر/اضافه‌کاری/غیبت هر پرسنل + جمع کل |
| 🖥 تابلوی زنده | ۷ شاخص لحظه‌ای + وضعیت تک‌تک پرسنل |

## 🚀 راه‌اندازی سریع

### پیش‌نیازها

|:---|:---|

| ویندوز کلاینت | 10+ با .NET 8 Desktop Runtime |

### ۱️⃣ API و دیتابیس

```bash
cd src/Sahand.ClinicPro.API
dotnet ef database update --project ../Sahand.ClinicPro.Infrastructure
dotnet run
```

| نشانی | شرح |
|:---|:---|
| `http://localhost:5000/swagger` | مستندات تعاملی API |
| `http://localhost:5000/health` | سنجه سلامت |
| `http://localhost:5000/hangfire` | داشبورد کارهای زمان‌بندی |

بذرهای خودکار: ۸ نقش، **۱۶۰+ دسترسی**، ادمین، ۱۴ تخصص، ICD-10، ۸ بیمه، **۳۰ ماژول لایسنس**

### ۲️⃣ ورود اول

| فیلد | مقدار |
|:---|:---|
| نام کاربری | `admin` |
| رمز عبور | `Admin@123` |

> ⚠️ تغییر رمز پس از نخستین ورود الزامی است (MustChangePassword)

### ۳️⃣ کلاینت دسکتاپ (ویندوز)

```bash
cd src/Sahand.ClinicPro.Desktop
dotnet run
```

نشانی API در `appsettings.json` کلاینت → `ApiSettings:BaseUrl`

### ۴️⃣ سرور لایسنس (اختیاری — cPanel/هاست اشتراکی)

```bash
# آپلود SahandClinicPro-LicenseServer-cPanel-vX.zip در ریشه هاست → استخراج → بازکردن /install.php
# فقط PHP 8 + MySQL — بدون Composer و بدون افزونه
```

<details>
<summary>⚙️ پیکربندی کلیدی (appsettings.json)</summary>

| `License:PortalUrl` | نشانی سرور لایسنس PHP |
| `License:RsaPublicKey` | کلید عمومی بررسی امضای لایسنس |
| `Sms:Kavenegar:ApiKey` | کلید پنل پیامک |
| `Government:Sepas` | نشانی و توکن سامانه سپاس |
</details>

## 🔐️ سامانه لایسنس

معماری سه‌طرفه با **سرور لایسنس PHP+MySQL بهینه cPanel** (بدون هیچ پیش‌نیاز):

```
┌────────────────┐    activate/validate/heartbeat    ┌─────────────────────┐
│  کلاینت WPF    │ ◄────────────────────────────► │  سرور لایسنس PHP     │
│  (فروش، آفلاین │     امضای RSA + اثر انگشت سخت‌افزار  │  (هاست اشتراکی)     │
│   تا ۳۰ روز)   │        + اطلاعات پشتیبانی 🆕        └─────────────────────┘
└────────────────┘
```

| ویژگی | شرح |
|:---|:---|
| 🔑 کلید | قالب `SCPRO-XXXXX-XXXXX-XXXXX` با الفبای بدون ابهام |
| 🧩 ماژول‌بندی | **۳۰ ماژول** جداگانه — از «بیماران» تا «نظرسنجی» |
| 📏 محدودیت‌ها | سقف کاربر/پزشک/بیمار/شعبه per-license |
| 🩺 اثر انگشت | قفل روی سخت‌افزار — جابه‌جایی با تشخیص سریال |
| 💓 تپ قلب | روزانه + مهلت آفلاین ۳۰ روز |
| 🧾 فعال‌سازی برون‌خط | فایل `.lic` امضاشده RSA |
| 🧑‍💻 **اطلاعات پشتیبانی پویا** 🆕 | نام/شرکت/تلفن/موبایل/ایمیل/وب از پنل قابل ویرایش — هنگام فعال‌سازی به کلاینت ارسال و سراسر برنامه نمایش داده می‌شود (بدون هاردکد) |
| 🛡 پنل مدیریت | داشبورد + لایسنس‌ها + فعال‌سازی‌ها + لاگ + تنظیمات + ویرایش پشتیبانی |
| 🧯 نرخ‌حدی و CSRF | محافظت خودکار در API و پنل |
