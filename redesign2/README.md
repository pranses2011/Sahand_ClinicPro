# 🎨 بازطراحیِ دوم — `redesign2`

بازطراحیِ کاملِ رابطِ کاربرِ **سهند کلینیک‌پرو** با ۸۱ فرم،
مشتق از وایرفریم‌های اختصاصی و آماده‌ی جایگزینی.

> این پوشه جایگزینِ `redesign/` (دورِ نخست) است که به دلیلِ
> **یکنواختیِ مولد** رد شد. تفاوتِ اصلی در جدولِ پایین آمده است.

## 🆚 تفاوت با دورِ نخست

| معیار | دورِ نخست (`redesign/`) ❌ | این دور (`redesign2/`) ✅ |
|---|---|---|
| روشِ تولید | یک قالبِ واحد برای همه‌ی فرم‌ها | **۱۹ چیدمانِ مستقل** — یکی برای هر کهن‌الگو |
| یکنواختی | «تقریباً یک شکل و زشت» | هر فرم ساختارِ خودش را دارد |

## 🧩 کهن‌الگوها

هر فرم بر پایه‌ی یکی از ۱۹ کهن‌الگوی زیر چیده شده است — **یک چیدمانِ مستقل
برای هر کدام**، نه یک قالبِ تکرارشونده:

| کهن‌الگو | تعداد | شرح |
|---|:--:|---|
| `list-dense` | ۱۵ | جدولِ فشرده با فیلتر و صفحه‌بندی |
| `dialog` | ۱۱ | پنجره‌ی گفتگو با یک یا دو اقدام |
| `form-std` | ۱۰ | فرمِ استاندارد روی شبکه‌ی ۱۲ ستونه |
| `detail-tabs` | ۱۰ | جزئیات با تب‌های چندگانه |
| `form-narrow` | ۸ | فرمِ تک‌ستونه (ورود، تغییرِ رمز) |
| `list-cards` | ۴ | لیستِ کارتیِ پاسخ‌گو |
| `form-lines` | ۴ | فرم با بخشِ اقلام و جمعِ کل |
| `settings` | ۳ | تنظیمات با فهرستِ بخش‌ها |
| `list-detail` | ۳ | جدول + پانلِ خلاصه |
| `split` | ۳ | دوپنلی با پانلِ کناریِ ثابت |
| `viewer` | ۲ | نمایشگر با بزرگ‌نمایی |
| `report` | ۲ | گزارش با فیلتر و خروجی |
| `dashboard` | ۱ | پیشخوان با کارت‌های شاخص و نمودار |
| `kanban` | ۱ | بوردِ کانبانِ نوبت‌ها |
| `pos` | ۱ | صندوقِ فروش با سبد |
| `detail-timeline` | ۱ | پرونده با خطِ زمانِ درمان |
| `splash` | ۱ | پنجره‌ی آغازین |
| `shell` | ۱ | پوسته‌ی اصلی (منو، محتوا، نوارِ وضعیت) |

## 🛠 مولدها و ابزارها

| ابزار | کار |
|---|---|
| `tools/spec_core.py` | مشخصاتِ ۸۱ فرم (فیلدها، ستون‌ها، دادهٔ نمونه، ارتباطات) |

| `tools/build_icons.py` | ساختِ `Assets/Icons.xaml` از Lucide |
| `tools/build_icon_preview.py` | صفحه‌ی نمایشِ آیکون‌ها |
| `tools/gen_views.py` | تولیدِ ۸۱ View |
| `tools/gen_viewmodels.py` | تولیدِ ۸۱ ViewModel |
| `tools/gen_docs.py` | فهرست‌ها و نمودارِ ارتباطات |
| `tools/gen_guide.py` | راهنمای جایگزینی |
| `tools/resx_sync.py` | همگام‌سازیِ دو زبان |
| `tools/audit_bindings.py` | ممیزیِ یکپارچگیِ اتصال‌ها |
