# 📌 تصمیم معماری — سرنوشت پنل Blazor لایسنس (LicensePortal)

> چرخه دوازدهم (D2) — مصوب بر اساس بند ۴-۷ سند تحلیل پروژه
> تاریخ: اکتبر ۲۰۲۶ (پاییز ۱۴۰۵)

## تصمیم

**آرشیو کامل `Sahand.ClinicPro.LicensePortal` و تک‌پشتی‌سازی روی پنل PHP خالص (`src/LicenseServer.Php`).**

پروژه از سولوشن حذف شد اما پوشه آن با همین سند نگه داشته می‌شود تا تاریخچه
کد برای مرجع باقی بماند. توسعه، تست و نگهداری آن متوقف است.

## دلایل

۱. **ناکامی هاست اشتراکی ایرانی:** LicensePortal به میزبانی ASP.NET Core نیازمند است؛
   در حالی‌که اکثر مشتریان هدف (درمانگاه‌های ایران) فقط هاست cPanel اشتراکی دارند که
   فقط PHP/MySQL اجرا می‌کند. پنل PHP دقیقاً برای همین محیط ساخته شده.

۲. **واگرایی جدی پیش‌رو:** با چرخه دوازدهم، پنل PHP به‌طور کامل حرفه‌ای شد —
   داشبورد نموداری (۴ نمودار SVG)، ویرایش/حذف لایسنس، اطلاعات کامل درمانگاه،
   پیام مستقیم به داشبورد، ۵ گزارش مدیریتی و انیمیشن‌های فراوان. پنل Blazor با
   ۵ صفحه ساده عملاً ۱۰٪ برابری-ویژگی دارد؛ نگهداری موازی یعنی دوباره‌کاری دائمی.

۳. **هزینه امنیتی دوگانه:** هر اصلاح امنیتی (CSRF، نشست، رمز) باید در دو کدبیس
   جدا انجام شود — سطح حمله را دو برابر می‌کند.

۴. **پوشش تست:** پنل PHP ۳۴ تست E2E واقعی دارد (نصب، صدور، پیام، حذف، مهاجرت)؛
   LicensePortal هیچ تست خودکاری ندارد.

## اگر در آینده پنل دات‌نتی لازم شد

سناریوی قابل قبول: مشتری با سرور اختصاصی ویندوزی که یکپارچگی با داشبورد Blazor
داخلی می‌خواهد. در آن صورت توصیه می‌شود به‌جای احیای این پروژه، از الگوی پنل PHP
به‌عنوان مشخصات مرجع (Spec) استفاده و پروژه تازه با feature-parity کامل ساخته شود.
