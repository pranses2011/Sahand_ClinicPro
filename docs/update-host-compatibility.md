# وابستگی‌های بستهٔ به‌روزرسانی کم‌حجم

نصب کامل خودبسنده است. بستهٔ سبک فایل‌های runtime نصب قبلی و
`runtimeconfig.json` آن را حفظ می‌کند، اما باید `deps.json` **خودبسندهٔ نسخهٔ
جدید** را جایگزین کند. نگه‌داشتن deps قدیمی باعث می‌شود DLL تازه‌ای مانند
HtmlSanitizer، حتی اگر کپی شده باشد، در بارگذاری برنامه پیدا نشود. جایگزینی
آن با deps نسخهٔ وابسته به فریم‌ورک نیز با نصب خودبسنده سازگار نیست.

فرایند ساخت، deps را از خروجی نصب کامل همان commit برمی‌دارد و یکسان‌بودن
آن را پیش از انتشار بررسی می‌کند. آزمون Windows یک برنامهٔ خودبسندهٔ قدیمی
را واقعاً اجرا می‌کند، بستهٔ سبک برنامهٔ جدید با وابستگی جدید را روی آن
می‌نشاند، runtimeconfig را حفظ می‌کند و اجرای وابستگی جدید را می‌سنجد.

این آزمون نمونه جایگزین نصب و ارتقای واقعی محصول روی همهٔ نسخه‌ها و درایورها
نیست؛ بهتر است قبل از ارتقای درمانگاه، از تنظیمات و داده‌ها پشتیبان گرفته
شود. Runtime نصب قبلی در آپدیت سبک به‌روزرسانی نمی‌شود؛ برای دریافت Runtime
تازه باید بستهٔ کامل نصب شود.
