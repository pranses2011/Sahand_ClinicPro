# داده‌ها در قالب چاپ HTML

بدنهٔ قالب را فقط فرد دارای مجوز ویرایش تنظیمات می‌تواند تغییر دهد و همچنان
HTML قابل ویرایش است؛ بنابراین **خود بدنهٔ قالب محتوای مورد اعتماد مدیر است**،
نه یک محیط ایزوله برای اجرای کد ناشناس. این تغییر محدود به محافظت از داده‌های
جایگزین‌شونده است و اجرای محتوای مخربِ نوشته‌شده در خود قالب را تضمین نمی‌کند.
قالب‌ها را فقط از منابع مورد اعتماد وارد کنید.

- مقادیر متنی از جمله نام بیمار، نشانی و شماره‌ها هنگام جایگذاری HTML-encode
  می‌شوند. فقط `items_html`، `tests_html` و `results_html` به‌عنوان قطعهٔ جدول
  پردازش می‌شوند؛ تگ‌های جدول و متن مجازند ولی اسکریپت، تصاویر، رویدادها،
  نشانی‌ها و استایل‌های خود قطعه حذف می‌شوند. استایل بدنهٔ قالب دست‌نخورده است.
- متغیرها باید در متن سند باشند، نه در صفت، توضیح HTML، اسکریپت، استایل یا
  `template`. قالب قدیمی با چنین کاربردی تا اصلاح آن ذخیره/رندر نمی‌شود؛
  پیش‌نمایش و چاپ خطا می‌دهند. متغیر را به داخل متن یک عنصر منتقل کنید.
- رنگ و فونت نامعتبرِ ذخیره‌شده هنگام رندر به پیش‌فرض امن برمی‌گردند.
- پیش‌نمایش و چاپ HTML همچنان از مرورگر داخلی استفاده می‌کنند. این محافظت
  جایگزین آزمون چاپ واقعی یا بازبینی امنیتی کامل بدنهٔ قالب نیست.
