## 📊 گام P1: تکمیل ۱۵ گزارش باقی‌مانده با کوئری واقعی

موجودیت‌های پشتیبان همه آماده‌اند (Payment / DoctorPayment / Expense / InsuranceClaim / InvoiceItem / PharmacyTransaction / Visit.StartTime-EndTime / Patient.PatientType-LastVisitDate-BirthDate).

- [x] **P1-الف ✅ 2026-10-05 — توسعه امضای `execute/{reportId}`**: پارامترهای `patientId`، `months`، `icd10`، `minAmount`، `insuranceId`، `doctorId` علاوه بر `fromDate/toDate/top`
- [x] **P1-ب ✅ 2026-10-05 — شش گزارش مالی**:
  - `patient-statement` — صورت‌حساب بیمار: فاکتورها + پرداخت‌های بازه + مانده نهایی
  - `cashier-daily` — صندوق روزانه: پرداخت‌های روز به تفکیک روش + مرجوعی + خالص
  - `doctor-commission` — کارانه پزشکان از DoctorPayment (جمع ناخالص/کسور/خالص + وضعیت)
  - `profit-loss` — سود و زیان دوره: درآمد فاکتورها − هزینه‌های Expense به تفکیک دسته
  - `accounts-receivable` — مطالبات بیمه‌ای از InsuranceClaim (ارسال‌شده/تأیید/رد + مانده مطالبه)
  - `payment-methods` — تفکیک روش‌های پرداخت با درصد سهم
- [x] **P1-ج ✅ 2026-10-05 — پنج گزارش بیمار**:
  - `patient-demographics` — ماتریس گروه سنی (نوزاد/کودک/نوجوان/جوان/میانسال/سالمند) × جنسیت
  - `patient-insurance` — توزیع بیماران بر اساس بیمه‌گر اصلی/تکمیلی/بدون بیمه
  - `chronic-diseases` — بیماران با تشخیص ICD-10 مزمن (فیلتر اختیاری کد) + فیلد ChronicDiseases پرونده
  - `vip-patients` — بیماران VIP/کارمند (PatientType) با آخرین مراجعه
  - `inactive-patients` — بدون مراجعه بیش از N ماه (پیش‌فرض ۶)
- [x] **P1-د ✅ 2026-10-05 — چهار گزارش عملیاتی**:
  - `avg-visit-duration` — میانگین مدت ویزیت هر پزشک از StartTime/EndTime کامل‌شده
  - `top-medications` — پرمصرف‌ترین داروها از تراکنش‌های Dispense
  - `visit-patterns` — ماتریس روز هفته (شنبه تا جمعه) × بازه ساعتی
  - `service-mix` — سهم هر خدمت از درآمد (InvoiceItem گروه‌بندی بر Service)
- [x] **P1-هـ** — حذف پیام «نسخه بعدی» — همه ۳۱ گزارش کاتالوگ واقعی شدند ✅ 2026-10-05
