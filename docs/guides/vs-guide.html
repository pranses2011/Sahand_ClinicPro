۱️⃣ این راهنما برای چیست؟

اگر می‌خواهید خودتان از سورس‌کد پروژه فایل exe بسازید (مثلاً برای نصب روی رایانه‌های درمانگاه یا اعمال تغییرات دلخواه در ظاهر فرم‌ها)، این راهنما دقیقاً همان است. اگر فقط می‌خواهید برنامه را نصب و استفاده کنید، به راهنمای نصب مراجعه کنید — این راهنما مخصوص حالت توسعه است.

👀 چه انتظاری داشته باشید: نیازی به دانش برنامه‌نویسی برای دنبال‌کردن این راهنما نیست؛ فقط باید بتوانید نرم‌افزار نصب کنید و روی دکمه‌ها کلیک کنید. برای بخش تغییر فرم‌ها آشنایی مقدمی با C# کمک می‌کند ولی اجباری نیست.

۲️⃣ قدم ۰: نصب پیش‌نیازها

۱

Visual Studio 2022 Community (نسخه رایگان مایکروسافت) را از این نشانی دانلود و نصب کنید:

https://visualstudio.microsoft.com/downloads/
(از بخش Community برای ویندوز — دکمه Free Download)
۲

هنگام نصب، ویژوال استودیو می‌پرسد چه اجزایی لازم دارید («Workloads»). حتماً این چهار مورد را تیک بزنید:

تیک بزنیدنام در فهرستبرای چه؟
☑.NET desktop developmentبرای برنامه ویندوزی (WPF) — مهم‌ترین مورد
☑ASP.NET and web developmentبرای بخش سرور (API) و پرتال لایسنس
☑.NET 8 SDK (در کارگاه دسکتاپ خودکار نصب می‌شود)زبان اجرای پروژه
☑Data storage and processing (اختیاری)ابزارهای دیتابیس برای کار با SQL Server

بعد روی Install کلیک کنید — حدود ۸ تا ۱۵ گیگابایت نصب می‌کند؛ صبور باشید ☕.

💡 اگر مایلید از خط فرمان هم استفاده کنید، NET 8 SDK. را جداگانه هم می‌توانید از https://dotnet.microsoft.com/download/dotnet/8.0 نصب کنید (برای روش Publish با ترمینال لازم می‌شود).

۳️⃣ قدم ۱: دانلود پروژه از گیت‌هاب

📥 روش الف) دانلود ساده ZIP — مناسب بار اول

۱

به صفحه مخزن پروژه بروید (نشانی را از سهند سرویس دریافت کنید؛ مخزن خصوصی است و با اکانت شما باز می‌شود). وارد شوید (Sign in با اکانت گیت‌هابی که دسترسی دارد).

۲

دکمه سبز ⟨⟩ Code را بزنید → روی Download ZIP کلیک کنید. فایلی مثل Sahand_ClinicPro-main.zip دانلود می‌شود.

۳

روی فایل ZIP راست‌کلیک → Extract All… → مقصدی مثل D:\SahandClinicPro را بزنید و Extract کنید. تمام! پوشه پروژه آماده است.

👀 چه انتظاری داشته باشید: پوشه‌ای با این ساختار می‌بینید (مختصر شده):
SahandClinicPro-main/ ├── src/ │ ├── Sahand.ClinicPro.Desktop/ ← برنامه ویندوزی (فرم‌ها اینجاست) │ ├── Sahand.ClinicPro.API/ ← سرور برنامه │ ├── Sahand.ClinicPro.Domain/ ← منطق اصلی │ ├── Sahand.ClinicPro.Application/ ← دستورها و اعتبارسنجی‌ها │ ├── Sahand.ClinicPro.Infrastructure/ ← دیتابیس و سرویس‌ها │ └── LicenseServer.Php/ ← سرور لایسنس cPanel ├── Sahand.ClinicPro.sln ← فایل اصلی که در ویژوال استودیو باز می‌کنید ├── docs/ └── installer/

🌳 روش ب) کلون با Git — مناسب دریافت تغییرات بعدی

۱

برنامه Git را از https://git-scm.com/download/win نصب کنید (همه تنظیمات پیش‌فرض، فقط Next بزنید).

۲

در صفحه مخزن، دکمه ⟨⟩ Code → HTTPS را بزنید و نشانی را کپی کنید. سپس در ویندوز روی دسکتاپ راست‌کلیک → Open Git Bash here و این دستور را بزنید (نشانی خودتان را جایگزین کنید):

git clone https://github.com/USERNAME/Sahand_ClinicPro.git D:/SahandClinicPro

اگر مخزن خصوصی است، گیت از شما نام کاربری و Token می‌خواهد — توکن را از Settings → Developer settings → Personal access tokens گیت‌هاب بسازید و به‌جای رمز بچسبانید.

💡 مزیت روش Git: دفعه بعد که فروشنده نسخه جدید گذاشت، فقط می‌زنید git pull و همه تغییرات می‌آید — لازم نیست از اول دانلود کنید.

۴️⃣ قدم ۲: باز کردن پروژه در ویژوال استودیو

۱

ویژوال استودیو 2022 را باز کنید → Open a project or solution → به پوشه پروژه بروید و فایل Sahand.ClinicPro.sln را انتخاب و باز کنید.

۲

چند لحظه صبر کنید تا «Solution Explorer» (پنجره راست) پر شود از پروژه‌ها. اگر پیام بارگذاری پروژه‌های .NET Framework ظاهر شد، روی Load کلیک کنید.

👀 چه انتظاری داشته باشید: بالای صفحه نوار سبز نیمه‌شفاف می‌آید با نوشته INCOMPATIBLE یا «توصیه می‌شود NET 8 SDK. نصب شود» اگر SDK ندارید — طبق قدم ۰ نصبش کنید و دوباره باز کنید.

۵️⃣ قدم ۳: بارگذاری کتابخانه‌ها (Restore) و بیلد اول

۱

از منوی بالا: Build → Rebuild Solution (کلید میانبر: Ctrl+Alt+F7). ویژوال استودیو خودکار همه کتابخانه‌های NuGet را دانلود می‌کند.

۲

پایین صفحه در پنجره Output پیشرفت را ببینید. بار اول ۳ تا ۱۰ دقیقه طول می‌کشد (دانلود از اینترنت). آخرش باید بنویسد:

Rebuild succeeded. 0 Warning(s).  0 Error(s).
👀 چه انتظاری داشته باشید: اگر عدد Error صفر بود 🎉؛ اگر نبود، جدول «خطاهای رایج» پایین همین راهنما را ببینید — ۹۵٪ خطاها همان سه‌تای اول آن جدول است.

۶️⃣ قدم ۴: اجرای برنامه (F5)

۱

در پنجره Solution Explorer روی پروژه Sahand.ClinicPro.Desktop راست‌کلیک → Set as Startup Project (نامش ضخیم می‌شود).

۲

دکمه سبز ▶ (یا کلید F5) را بزنید. برنامه کامپایل و اجرا می‌شود و پنجره ورود درمانگاه باز می‌شود. برای اجرای سریع‌تر بدون دیباگر: Ctrl+F5.

⚠️ برای کار کامل، باید سرور برنامه (API) هم در حال اجرا باشد: روی Sahand.ClinicPro.API راست‌کلیک → Debug → Start new instance — یا از ترمینال: dotnet run --project src/Sahand.ClinicPro.API

۷️⃣ قدم ۵: ساخت فایل exe (Publish) — سه روش

🥇 روش الف) تک‌فایل خودکفا (پیشنهادی — مثل نصب ساده)

خروجی: یک فایل exe واحد که همه‌چیز داخلش هست — نیازی به نصب NET. روی رایانه مقصد ندارد.

۱

روی Sahand.ClinicPro.Desktop راست‌کلیک → Publish… (یا منوی Build → Publish Selection).

۲

هدف (Target) را Folder انتخاب کنید → دکمه Next → پوشه مقصد مثلاً D:\Publish\ClinicPro → Next → Finish.

۳

حالا مهم‌ترین قسمت: روی نشانگر پروفایل (که ساخته شد، معمولاً FolderProfile.pubxml) دوبار کلیک کنید و حالت انتشار را تنظیم کنید — یا ساده‌تر: در صفحه Publish روی Show all settings بزنید و این‌ها را انتخاب کنید:

تنظیممقدار پیشنهادیچرا؟
Deployment modeSelf-containedیعنی NET. لازم نیست روی رایانه مقصد نصب باشد
Target runtimewin-x64برای ویندوز ۶۴ بیتی (اکثر رایانه‌های امروزی)
Produce single fileتیک بزنید ✔همه فایل‌ها داخل یک exe جمع می‌شوند
Enable ReadyToRun compilationتیک بزنید ✔برنامه سریع‌تر باز می‌شود
۴

دکمه Publish را بزنید. بعد از چند دقیقه در پوشه مقصد یک فایل مثل این دارید:

D:\Publish\ClinicPro\Sahand.ClinicPro.Desktop.exe   (~120–170 MB چون همه‌چیز داخلش است)

این فایل را هر جا ببرید (فلش، شبکه، نصب‌کننده Inno Setup) مستقل اجرا می‌شود.

🥈 روش ب) خط فرمان (برای اسکریپت و تکرار سریع)

در پوشه اصلی پروژه، ترمینال باز کنید (نوع cmd در نوار آدرس فایل‌اکسپلورر) و بزنید:

cd src\Sahand.ClinicPro.Desktop
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:EnableReadyToRun=true ^
  -o D:\Publish\ClinicPro

نتیجه همان است — یک exe واحد در پوشه D:\Publish\ClinicPro.

🥉 روش ج) بسته کامل نصب با Inno Setup (مثل نصب‌کننده‌های حرفه‌ای)

۱

برنامه Inno Setup 6 را از https://jrsoftware.org/isdl.php نصب کنید (رایگان).

۲

در پوشه installer پروژه فایل sahand.iss آماده است. آن را با Inno Setup باز کنید و روی Compile ▶ بزنید. خروجی: SahandClinicPro-Setup.exe — یک نصب‌کننده فارسی کامل با دکمه «بعدی/نصب» و میانبر دسکتاپ.

۸️⃣ قدم ۶: تغییر عناصر فرم‌ها

همه فرم‌های برنامه در پوشه src/Sahand.ClinicPro.Desktop/Views هستند؛ هر فرم دو فایل دارد: XxxView.xaml (ظاهر فرم) و XxxView.xaml.cs (رفتار). منطق نمایشی هم در ViewModels است.

✏️ الف) تغییر متن دکمه/عنوان

۱

مثلاً می‌خواهید متن دکمه صفحه ورود عوض شود: در Solution Explorer به مسیر Desktop → Views → LoginWindow.xaml بروید و دوبار کلیک کنید.

۲

در کد XAML که باز می‌شود، متن موردنظر را پیدا کنید (مثلاً Text="ورود به سیستم") و به دلخواه تغییرش دهید. با Ctrl+S ذخیره کنید.

۳

F5 بزنید — تغییر را می‌بینید. این روش برای متن‌ها، ایموجی‌ها و رنگ‌ها یکسان است.

🎨 ب) تغییر رنگ/فونت

رنگ‌ها به شکل Background="#1565C0" در XAML آمده‌اند. کد رنگ‌ها «HEX» است؛ از سایت‌هایی مثل colorpicker.me رنگ دلخواه را انتخاب و کدش را جایگزین کنید. فونت سراسری در App.xaml تنظیم می‌شود (پیش‌فرض: وزیرمتن).

📐 ج) جابه‌جایی عناصر

چیدمان فرم‌ها با Grid و StackPanel سازمان‌یافته است: Margin="راست,بالا,چپ,پایین" فاصله هر عنصر را کنترل می‌کند. مثلاً Margin="0,10,0,0" یعنی «۱۰ پیکسل از بالا فاصله بده». برای دیدن نتیجه بدون اجرا، در ویژوال استودیو دکمه Design پایینِ محیط باز شدن XAML را بزنید (پیش‌نمایش زنده).

⚠️ دو نکته: ① حتماً قبل از هر تغییر، از فایل اصلی یک کپی بگیرید (یا git commit بزنید) تا اگر خراب شد برگردانید. ② مقادیر اطلاعات پشتیبانی را در کد تغییر ندهید — آن‌ها از سرور لایسنس می‌آیند و باید از پنل مدیریت لایسنس ویرایش شوند.

🧭 د) تغییر ترتیب منوها

فهرست منوی راست برنامه در ViewModels/MainWindowViewModel.cs تعریف شده (بخش NavItems). هر خط یک منوست؛ می‌توانید ترتیب، عنوان یا آیکون (از کتابخانه Material Design Icons) را عوض کنید.

🔟 پرسش‌های پرتکرار

پرسشپاسخ
چرا حجم فایل exe بزرگ است؟چون حالت Self-contained کل موتور NET. را داخل فایل می‌گذارد تا روی هر ویندوزی بدون پیش‌نیاز اجرا شود. اگر حجم برایتان مهم نیست و می‌توانید NET 8. را روی رایانه‌ها نصب کنید، حالت Framework-dependent حجم را به حدود ۱۵ مگابایت می‌رساند.
می‌توانم فقط بخشی از پروژه را بیلد کنم؟بله — روی همان پروژه راست‌کلیک → Build. ولی برای اجرای کامل دسکتاپ، API و وابسته‌ها باید بیلد شوند؛ ساده‌ترین راه همان Rebuild Solution است.
تغییرم را برای فروشنده بفرستم؟اگر با Git کار می‌کنید: git add . → git commit -m "توضیح تغییر" → git push. اگر نه، فایل(های) تغییر‌یافته را ایمیل کنید.
فونت فارسی برنامه چیست و چطور عوضش کنم؟وزیرمتن (Vazirmatn) است؛ فایل‌هایش در Desktop/Assets/Fonts. برای تعویض، فونت جدید را همان‌جا بگذارید و نامش را در App.xaml جایگزین کنید.
آیا تغییر ظاهر فرم‌ها لایسنس را باطل می‌کند؟نه — لایسنس به سخت‌افزار و کلید قفل است؛ تغییر ظاهر و حتی منطق داخلی تاثیری روی فعال‌سازی ندارد (تا وقتی سرور لایسنس همان باشد).
