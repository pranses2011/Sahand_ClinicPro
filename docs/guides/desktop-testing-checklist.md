# 🖥️ چک‌لیست تست دستی کلاینت WPF

> کلاینت روی ویندوز ساخته و اجرا می‌شود؛ این چک‌لیست پس از هر انتشار اجرا شود.

## ورود
- [ ] ورود با admin/Admin@123 و پیام الزام تغییر رمز
- [ ] ورود اشتباه ×۵ → قفل ۳۰ دقیقه با شمارش معکوس
- [ ] Enter در فیلد رمز = دکمه ورود
- [ ] نمایش خطای فارسی هنگام قطع سرور

## داشبورد
- [ ] چهار کارت آمار با اعداد واقعی دیتابیس
- [ ] تاریخ شمسی درست هدر و کارت‌ها
- [ ] کلید تم: روشن ↔ تیره بدون خطا

## بیماران
- [ ] جستجو با نام/کد ملی/موبایل/شماره پرونده
- [ ] صفحه‌بندی: بعد/قبل و شمارنده «صفحه X از Y»
- [ ] ثبت بیمار جدید → شماره پرونده MRN-xxxxxx خودکار
- [ ] ویرایش و ذخیره موفق
- [ ] کد ملی تکراری → پیام «قبلاً ثبت شده»
- [ ] دابل‌کلیک ردیف → فرم ویرایش

## نشست
- [ ] خروج → بازگشت به پنجره ورود و ابطال توکن
- [ ] انقضای توکن → رفتن خودکار به ورود (پس از ۳۰ دقیقه بی‌کاری)
- [ ] توکن بعد از راه‌اندازی مجدد برنامه ماندگار است

## عمومی
- [ ] فونت وزیرمتن در همه صفحات
- [ ] چیدمان RTL صحیح (ستون کنار سمت راست)
- [ ] پیام‌های خطای سرور فارسی و خوانا
- [ ] کلیدهای میانبر در فرم‌ها
