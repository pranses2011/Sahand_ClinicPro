۱️⃣ قبل از شروع — ۳ چیزی که باید بدانید

این راهنما طوری نوشته شده که حتی اگر تا امروز هیچ نرم‌افزاری نصب نکرده باشید، بتوانید با آرامش قدم‌به‌قدم پیش بروید. هر جا باید روی چیزی کلیک کنید، نام دقیق همان دکمه را داخل کادر خاکستری آورده‌ایم؛ مثل این: Next. هر جا لازم باشد بدانید چه چیزی قرار است روی صفحه ظاهر شود، کادر بنفش «چه انتظاری داشته باشید» گذاشته‌ایم.

👀 چه انتظاری داشته باشید: نصب کامل معمولاً بین ۴۵ تا ۹۰ دقیقه زمان می‌برد. لازم نیست همه را یک روزه انجام دهید — می‌توانید بعد از هر قدم استراحت کنید؛ چیزی خراب نمی‌شود.

۱) سه لایه داریم: «سرور» یعنی رایانه‌ای که انبار اطلاعات شماست (مثل دفترچه مرکزی). «کلاینت» یعنی رایانه‌ای که کاربران با آن کار می‌کنند (پذیرش، اتاق پزشک و…). «سرور لایسنس» یعنی یک وب‌سایت کوچک روی اینترنت که اجازه کار برنامه را کنترل می‌کند — آن را فروشنده (سهند سرویس) برایتان آماده می‌کند.

۲) ترتیب مهم است: اول سرور، بعد کلاینت‌ها. اگر جا بپرید، برنامه پیام خطا می‌دهد — نگران نباشید، در جدول رفع اشکال انتهای همین راهنما همه خطاهای رایج و راه‌حلشان هست.

۳) هیچ‌وقت با دکمه Power خاموش نکنید: مخصوصاً رایانه سرور را همیشه از منوی Start → Power → Shut down خاموش کنید تا اطلاعات آسیب نبیند. توصیه می‌کنیم سرور را اصلاً خاموش نکنید و فقط صفحه‌نمایشش را ببندید.

۳️⃣ روی کدام رایانه چه چیزی نصب می‌شود؟

رایانهچه چیزی نصب می‌شود؟چرا؟
سرور (رایانه مرکزی)① SQL Server (انبان اطلاعات) ② سرور برنامه (API) ③ خود نرم‌افزار برای تستهمه اطلاعات اینجا ذخیره می‌شود؛ بقیه رایانه‌ها از اینجا می‌خوانند.
کلاینت‌ها (پذیرش و اتاق‌ها)فقط خود نرم‌افزار درمانگاهسبک و سریع است؛ نصبش ۲ دقیقه طول می‌کشد.
سرور لایسنس (روی اینترنت)هیچ‌چیز — این بخش توسط سهند سرویس روی هاست شما نصب می‌شودمثل یک قفل مرکزی که اجازه کار برنامه را می‌دهد.

۴️⃣ قدم ۱: نصب SQL Server روی رایانه سرور

SQL Server همان «دفترچه مرکزی» است که همه اطلاعات درمانگاه در آن نوشته می‌شود. فقط روی رایانه سرور نصب می‌شود — روی رایانه‌های کاربران نصب نکنید.

۱

در مرورگر (Chrome یا Edge) این نشانی را باز کنید و دکمه Download now را بزنید:

https://www.microsoft.com/en-us/download/details.aspx?id=104781
(جستجوی گوگل: SQL Server 2022 Express download)
۲

فایل دانلودشده معمولاً به نام SQLServer2022-SSEI-Expr.exe است. روی آن دوبار کلیک کنید. اگر پنجره‌ی «User Account Control» آمد و پرسید اجازه تغییر بدهم؟، روی Yes کلیک کنید.

👀 چه انتظاری داشته باشید: یک پنجره کوچک باز می‌شود با سه گزینه: Basic / Custom / Download Media. گزینه Basic (پیش‌فرض) همان چیزی است که می‌خواهیم.
۳

روی Accept و بعد Install کلیک کنید و صبر کنید. یک چای بخورید ☕ — این مرحله ۳ تا ۸ دقیقه طول می‌کشد.

۴

وقتی تمام شد، صفحه‌ای مثل تصویر زیر می‌بینید. از قسمت Connection string متن کنار Data Source= را یادداشت کنید (معمولاً localhost\SQLEXPRESS است) — بعداً لازمش داریم.

محیط نصب SQL Server — این مرحله فقط روی رایانه سرور انجام می‌شود
⚠️ مهم: اگر پیام «Restart is required» (نیاز به ری‌استارت) دیدید، رایانه را ری‌استارت کنید و از همین قدم ۴ ادامه دهید.

۵️⃣ قدم ۲: آماده‌سازی سرور اصلی برنامه (API)

بسته نصب را از لینک رلیز گیت‌هاب دانلود کنید: SahandClinicPro-Setup-v1.6.0.zip را باز کنید و روی رایانه سرور، پوشه server را داخل C:\SahandClinicPro کپی کنید. روی فایل Sahand.ClinicPro.API.exe دوبار کلیک کنید.

👀 چه انتظاری داشته باشید: یک پنجره سیاه (کنسول) باز می‌شود و چند خط سبز می‌نویسد و می‌ایستد روی جمله Now listening on: http://0.0.0.0:5000 — یعنی سرور با موفقیت روشن شده. این پنجره سیاه را نبندید! همان‌طور باز بمانید. اگر Firewall ویندوز پرسید، Allow access را بزنید.
کنسول سرور برنامه — نوشتن Now listening یعنی همه‌چیز درست است

برای اینکه این سرور هر وقت ویندوز بالا آمد خودکار روشن شود، از منوی Start تایپ کنید Task Scheduler و یک وظیفه جدید بسازید که Sahand.ClinicPro.API.exe را هنگام روشن‌شدن ویندوز اجرا کند (در نسخه بعدی، نصب‌کننده خودکار این کار را می‌کند).

۶️⃣ قدم ۳: نصب نرم‌افزار روی رایانه‌های کاربران

۱

روی هر رایانه کاربر، فایل نصب SahandClinicPro-Setup.exe را (از همان ZIP) اجرا کنید. اگر پیام ویندوز SmartScreen آمد، روی More info و بعد Run anyway کلیک کنید — این پیام فقط برای نرم‌افزارهای جدید و شناخته‌نشده نمایش داده می‌شود و جای نگرانی نیست.

۲

در پنجره نصب، پوشه پیش‌فرض (C:\Program Files\Sahand ClinicPro) را قبول کنید و Next → Install → Finish بزنید. آیکون برنامه روی دسکتاپ ظاهر می‌شود.

۳

اولین بار که برنامه را باز کنید، صفحه ورود مثل تصویر زیر می‌آید. اگر پیام «اتصال به سرور برقرار نشد» گرفتید، هنوز تنظیمات شبکه (قدم ۵) را انجام نداده‌اید — اشکالی ندارد؛ بعد از قدم ۵ درست می‌شود.

صفحه ورود نرم‌افزار — نام کاربری اولیه: admin (رمز را هنگام اولین ورود عوض کنید)

۷️⃣ قدم ۴: فعال‌سازی لایسنس — اولین کار بعد از نصب

۱

کلید لایسنس را از سهند سرویس گرفته‌اید (قالبش این‌طور است: SCPRO-XXXXX-XXXXX-XXXXX). وارد برنامه شوید و از منوی راست، روی لایسنس کلیک کنید.

۲

کلید را در کادر «کلید لایسنس» تایپ کنید (کپی‌پیست بهتر است) و دکمه 🔑 فعال‌سازی آنلاین را بزنید. باید اینترنت وصل باشد.

👀 چه انتظاری داشته باشید: پیام سبز «لایسنس فعال شد» می‌بینید و لیست ماژول‌های خریداری‌شده تیک سبز می‌خورند. همچنین کارت پشتیبانی با نام و شماره تماس واقعی فروشنده پایین صفحه ظاهر می‌شود — این اطلاعات هر بار از سرور لایسنس تازه می‌شود.
صفحه وضعیت لایسنس — کارت پشتیبانی پایین صفحه به‌صورت خودکار از سرور دریافت می‌شود
⚠️ اگر اینترنت درمانگاه قطعی است: از فروشنده «فایل لایسنس آفلاین» با پسوند .lic بگیرید و با دکمه 📤 بارگذاری فایل لایسنس (.lic) فعال کنید — نتیجه یکی است.

۸️⃣ قدم ۵: تنظیمات شبکه — وصل‌کردن رایانه‌ها به هم

هدف این قدم: رایانه‌های کاربران بتوانند به رایانه سرور «بروازند». دو کار کوچک لازم است: (الف) به سرور یک نشانی ثابت بدهیم، (ب) در فایروال سرور راه را باز کنیم.

📌 الف) نشانی ثابت (IP) به سرور

۱

روی رایانه سرور: از منوی Start روی آیکون شبکه (کنار ساعت) راست‌کلیک → Open Network & Internet settings → روی Change adapter options کلیک کنید.

۲

روی اتصال فعال (Ethernet یا Wi-Fi) دوبار کلیک → Properties → روی Internet Protocol Version 4 (TCP/IPv4) دوبار کلیک کنید.

۳

گزینه Use the following IP address را انتخاب و این مقادیر را بنویسید:

IP address:      192.168.1.10
Subnet mask:     255.255.255.0
Default gateway: 192.168.1.1
Preferred DNS:   192.168.1.1

سه بار OK بزنید. (اگر مودم شما شبکه دیگری می‌دهد — مثلاً ۱۹۲.۱۶۸.۰ — فقط بخش آخر نشانی سرور را ۱۰ بگذارید؛ مثل 192.168.0.10)

🧱 ب) بازکردن راه در فایروال سرور

۱

از منوی Start تایپ کنید Windows Defender Firewall → از چپ Advanced settings → از چپ Inbound Rules → از راست New Rule…

۲

سه بار این مراحل را (برای هر پورت یک‌بار) تکرار کنید: Port → TCP → شماره پورت را بنویسید (5000 و بعد 1433) → Allow the connection → هر سه تیک را بزنید → نام بگذارید مثل Sahand API → Finish. یک‌بار هم برای UDP پورت 1434.

قواعد فایروال پس از ساخت — سه قاعده سبز یعنی راه سرور باز است

🖥 ج) تنظیم کلاینت‌ها

۱

روی هر رایانه کاربر، در فایل پیکربندی برنامه (منوی تنظیمات → اتصال سرور) نشانی سرور را به‌جای localhost بنویسید: http://192.168.1.10:5000 — دقیقاً همان نشانی‌ای که در بخش الف به سرور دادید.

۲

برنامه را ببندید و دوباره باز کنید. حالا باید صفحه ورود بدون خطا بیاید و نام سرور در نوار پایین برنامه سبز باشد. تبریک! 🎉 شبکه شما آماده است.

نقشه شبکه پیشنهادی — نشانی سرور را در همه کلاینت‌ها یکسان وارد کنید

۹️⃣ قدم ۶: اتصال دستگاه حضور و غیاب (اختیاری)

۱

دستگاه را با کابل شبکه به مودم وصل کنید و طبق دفترچه دستگاه، به آن نشانی ثابت بدهید (مثلاً 192.168.1.50).

۲

در برنامه به منوی حضور و غیاب → تب مدیریت دستگاه‌ها → دکمه ➕ افزودن دستگاه و نشانی و پورت دستگاه را وارد کنید (ZKTeco پیش‌فرض ۴۳۷۰، Hikvision پیش‌فرض ۸۰).

۳

روی 🔌 تست اتصال کلیک کنید — سبز شد؟ تمام! از این لحظه هر ضربه‌ی اثرانگشت خودکار داخل برنامه می‌آید.

تب مدیریت دستگاه‌ها — پس از تست موفق، وضعیت دستگاه «متصل» می‌شود

🔟 قدم ۷: روشن‌کردن پشتیبان‌گیری خودکار

۱

منوی بکاپ و بازیابی → قسمت زمان‌بندی → گزینه «روزانه ساعت ۰۳:۰۰ بامداد» را فعال کنید و پوشه مقصد را یک درایو دیگر (مثلاً فلش یا هارد اکسترنال E:) انتخاب کنید.

⚠️ قانون طلایی: اگر بکاپ روی همان هاردی باشد که ویندوز نصب است، خرابی هارد یعنی از دست رفتن همه اطلاعات. یک هارد اکسترنال ساده ۱ ترابایتی چند صد هزار تومان است — ارزشش را دارد.
