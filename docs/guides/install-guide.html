۱️⃣ معرفی و معماری استقرار

سامانه درمانگاه سهند با معماری سرور-کلاینت کار می‌کند: یک رایانه مرکزی (سرور) به عنوان میزبان دیتابیس و API عمل می‌کند و رایانه‌های کاربران (کلاینت‌ها) از طریق شبکه محلی به آن متصل می‌شوند. سرور لایسنس جداگانه روی هاست اینترنتی قرار می‌گیرد و دستگاه حضور و غیاب مستقیماً به شبکه محلی متصل است.

۳️⃣ نصب و پیکربندی SQL Server

۱
دانلود و اجرای نصاب: نسخه مناسب را دانلود کنید و نصاب را با دسترسی Administrator اجرا کنید. در صفحه Installation گزینه New SQL Server stand-alone installation را انتخاب کنید.
۲
انتخاب نسخه: گزینه Express (رایگان) یا کلید نسخه استاندارد را وارد کنید.
۳
پیکربندی مهم: در بخش Authentication Mode حتماً گزینه Mixed Mode را انتخاب کنید و رمز قوی برای کاربر sa تعیین کنید (نوشتن رمز در محل امن الزامی است).
۴
فعال‌سازی TCP/IP: در SQL Server Configuration Manager:
  • مسیر: SQL Server Network Configuration → Protocols for MSSQLSERVER
  • گزینه TCP/IP را Enable کنید
  • دکمه SQL Server Services → سرویس SQL Server را Restart کنید
✅ آزمون موفقیت: روی رایانه کلاینت در SSMS با IPسرور,1433 (مثلاً 192.168.1.10,1433) و Authentication از نوع SQL Server متصل شوید — اگر اتصال برقرار شد، دیتابیس برای شبکه آماده است.

۴️⃣ نصب سرور اصلی (API) روی ویندوز

۱
اجراه بسته نصبی سرور: فایل SahandClinicPro-Setup-v1.4.0.zip را روی رایانه سرور استخراج کنید و INSTALL-SERVER.bat را با دسترسی Administrator اجرا کنید. اسکریپت به‌صورت خودکار:
  • پیش‌نیازها را بررسی و دانلود می‌کند
  • فایل‌های API را در C:\SahandClinicPro\Server منتشر می‌کند
  • سرویس ویندوزی SahandClinicPro.API را با شروع خودکار ثبت می‌کند
۲
پیکربندی اتصال دیتابیس: فایل appsettings.json در پوشه نصب را ویرایش کنید: 
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=192.168.1.10;Database=ClinicProDb;
                          User Id=sa;Password=رمز‌شما;TrustServerCertificate=True;"
  },
  "Jwt": {
    "SecretKey": "یک-کلید-تصادفی-حداقل-۶۴-کاراکتری-منحصربه‌فرد"
  }
}
⛔ هرگز از رمز پیش‌فرض یا کلید JWT نمونه در محیط واقعی استفاده نکنید — کلید تصادفی با دستور openssl rand -base64 48 یا ابزار Password Generator بسازید.
۳
ساخت دیتابیس و جداول: در خط فرمان (cmd): 
cd C:\SahandClinicPro\Server
dotnet Sahand.ClinicPro.API.dll ef database update
خروجی موفق: پیام Applying migration '20261005101427_AttendanceDeviceModule' — یعنی ۹۳ جدول شامل جداول حضور و غیاب ساخته شده است.
۴
شروع سرویس و آزمون: 
net start SahandClinicPro.API
سپس در مرورگر سرور نشانی http://localhost:5000/health را باز کنید — پاسخ {"status":"Healthy"} یعنی سرور زنده است. Swagger روی /swagger و داشبورد کارهای زمان‌بندی روی /hangfire در دسترس‌اند.

۵️⃣ نصب کلاینت دسکتاپ روی رایانه‌های کاربران

۱
اجرای نصاب: روی هر رایانه کاربر، فایل SahandClinicPro-Setup-v1.4.0.exe را اجرا کنید. نصاب Inno Setup تمام پیش‌نیازها (شامل .NET 8 Desktop Runtime) را خودکار نصب می‌کند و میان‌بر روی دسکتاپ و منوی استارت می‌سازد.
۲
نشانی سرور: در نخستین اجرا، پنجره تنظیمات با عنوان «تنظیمات اتصال به سرور» باز می‌شود. نشانی API را وارد کنید:
حالتنشانی
سرور در همان رایانهhttp://localhost:5000
سرور روی شبکه محلیhttp://192.168.1.10:5000
۳
ورود اول: با حساب مدیر وارد شوید — در اولین ورود، تغییر رمز اجباری است.

📸 پنجره ورود نرم‌افزار

پنجره ورود — پیش از فعال‌سازی لایسنس، هشدار فعال‌سازی نمایش داده می‌شود

💡 نصب بی‌صدا (Silent) برای نصب گروهی: در خط فرمان: SahandClinicPro-Setup-v1.4.0.exe /SILENT — بدون تعامل کاربر نصب می‌شود؛ مناسب ۲۰ کلاینت با ابزارهای انتقال نرم‌افزار (PDQ/GPO).

۶️⃣ راه‌اندازی سرور لایسنس روی هاست cPanel

سرور لایسنس یک برنامه سبک PHP+MySQL است که روی هر هاست اشتراکی cPanel (بدون Composer و بدون افزونه خاص) نصب می‌شود و مدیریت کلیدها و فعال‌سازی‌های نرم‌افزار را بر عهده دارد.

۱
آپلود بسته: وارد cPanel شوید → File Manager → پوشه public_html یا زیردامنه دلخواه (مثلاً license.yourclinic.ir). فایل Sahand-LicenseServer-cPanel-v1.1.zip را آپلود و با گزینه Extract استخراج کنید.
۲
ساخت دیتابیس: در cPanel بخش MySQL Database Wizard:
  • نام دیتابیس: clinicpro_license
  • کاربر و رمز قوی بسازید و ALL PRIVILEGES بدهید
  • اطلاعات را یادداشت کنید — در مرحله بعد لازم است
۳
اجرای نصب‌کننده چهار مرحله‌ای: در مرورگر نشانی https://license.yourclinic.ir/install.php را باز کنید:
مرحلهاقدام
① بررسی پیش‌نیازPHP 8+ و افزونه‌های پایه — معمولاً همه سبز است
② اتصال دیتابیسمشخصات MySQL مرحله قبل را وارد کنید
③ ساخت مدیرنام کاربری و رمز قوی مدیر لایسنس
④ پایاننصب کامل شد — پوشه install خودکار قفل می‌شود
🔒 امنیت: حتماً روی دامنه، گواهی SSL (Let's Encrypt رایگان در cPanel) فعال کنید — ارتباط لایسنس حتماً باید HTTPS باشد. پس از نصب، فایل install.php خودکار قفل می‌شود؛ برای نصب مجدد باید دستی آن را در File Manager حذف کنید.
۴
صدور نخستین لایسنس: وارد پنل مدیریت شوید (/index.php) → منوی لایسنس‌ها → صدور لایسنس جدید:
  • نام درمانگاه، سقف کاربر/پزشک/بیمار/شعبه را تعیین کنید
  • ماژول‌های فعال را علامت بزنید — ماژول‌های اصلی به‌صورت پیش‌فرض فعال‌اند
  • ماژول «حضور و غیاب» را برای فعال‌سازی قابلیت دستگاه‌ها علامت بزنید ⭐
  • روی 🔑 صدور لایسنس کلیک کنید — کلید با قالب SCPRO-XXXXX-XXXXX-XXXXX صادر می‌شود

۷️⃣ فعال‌سازی لایسنس در نرم‌افزار

۱
تنظیم نشانی سرور لایسنس: در کلاینت وارد تنظیمات → لایسنس شوید. در فیلد نشانی سرور لایسنس نشانی کامل پنل را وارد کنید: https://license.yourclinic.ir/api.php
۲
فعال‌سازی برخط: کلید ۲۴ کاراکتری دریافتی از پنل را در کادر کلید فعال‌سازی وارد و روی فعال‌سازی کلیک کنید. پیام موفقیت: «لایسنس با موفقیت فعال شد» — وضعیت همه ماژول‌ها در همان صفحه نمایان می‌شود.
۳
حالت برون‌خط (در صورت قطعیت اینترنت): از پنل مدیریت لایسنس، فایل .lic مخصوص همین درمانگاه را دانلود و در همین صفحه گزینه بارگذاری فایل لایسنس انتخاب کنید. فایل با امضای RSA است و تا ۳۰ روز آفلاین معتبر می‌ماند.

۸️⃣ پیکربندی شبکه درمانگاه

📌 تخصیص IP ثابت به سرور

روی رایانه سرور یک IP ثابت تنظیم کنید تا کلاینت‌ها همیشه به یک نشانی ثابت متصل شوند:

تنظیممقدار نمونه
آدرس IP192.168.1.10
subnet Mask255.255.255.0
درگاه پیش‌فرض192.168.1.1 (مودم/روتر)
DNS178.22.122.100 و 8.8.8.8

مسیر: Settings → Network → Change adapter options → Ethernet → Properties → IPv4

🧱 پورت‌های مورد نیاز و فایروال

پورتپروتکلجهتکاربرد

5000TCP/HTTPسرور ⇄ کلاینتAPI اصلی

🧱
ساخت قانون فایروال (روی سرور): در PowerShell با دسترسی Administrator: 
New-NetFirewallRule -DisplayName "Sahand API"     -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow
New-NetFirewallRule -DisplayName "SQL Server"    -Direction Inbound -Protocol TCP -LocalPort 1433 -Action Allow
New-NetFirewallRule -DisplayName "ZKTeco Pull"   -Direction Outbound -Protocol TCP -RemotePort 4370 -Action Allow
💡 اگر شبکه درمانگاه دامنه (Active Directory) دارد، می‌توانید قانون‌ها را با Group Policy یک‌جا روی همه کلاینت‌ها اعمال کنید.

۹️⃣ اتصال دستگاه حضور و غیاب ⭐ جدید

از نسخه ۱.۳.۰ نرم‌افزار به‌صورت بومی با دستگاه‌های ZKTeco (پروتکل PULL) و Hikvision (ISAPI) ارتباط برقرار می‌کند — بدون هیچ نرم‌افزار واسط.

🔧 آماده‌سازی فیزیکی دستگاه ZKTeco (نمونه K40)

۱
دستگاه را با کابل شبکه به سوئیچ درمانگاه وصل کنید. منوی دستگاه: Menu → Comm. → Ethernet و IP ثابت بدهید (مثلاً 192.168.1.201، درگاه 255.255.255.0). پورت پیش‌فرض ۴۳۷۰ است و نیازی به تغییر نیست.
۲
اگر دستگاه رمز ادمین دارد، آن را ثبت کنید — در نرم‌افزار فیلد «کلید ارتباطی» همان رمز است.

۲
روی 📡 آزمون اتصال کلیک کنید — پیام «اتصال برقرار است — سریال: …» یعنی پروتکل به‌درستی کار می‌کند. سپس 💾 ذخیره کنید.
۳
نگاشت کاربران: هر پرسنل روی دستگاه یک شناسه عددی (Enroll) دارد — آن را در فرم نگاشت وارد کنید و به پرسنل متصل کنید. برای دیدن شناسه: روی دستگاه Menu → Users → هر کاربر ID دارد.
۴
روی 🔄 همگام‌سازی کلیک کنید — همه ضربه‌های ذخیره‌شده دستگاه دریافت و پردازش می‌شوند. از این پس کار زمان‌بندی‌شده هر ۵ دقیقه (قابل تنظیم) خودکار سینک می‌کند.

⏰ تعریف شیفت و تخصیص

در تب شیفت‌ها شیفت درمانگاه را تعریف کنید (مثال شیفت صبح: ۰۸:۰۰ تا ۱۶:۰۰ با تحمل تأخیر ۱۰ دقیقه) و سپس به هر پرسنل تخصیص دهید. محاسبات تأخیر/تعجیل/اضافه‌کاری خودکار بر اساس همین شیفت انجام می‌شود.

وضعیت ضربهنمایش در نرم‌افزار
ورود تا ۱۰ دقیقه دیرتر🟢 حاضر — بدون تأخیر (داخل سقف تحمل)
ورود ۳۰ دقیقه دیرتر🟠 تأخیر — ۲۰ دقیقه (۳۰ منهای تحمل ۱۰)
خروج ۲ ساعت بعد از پایان شیفت🟢 حاضر + اضافه‌کاری ۱:۴۵ (با آستانه ۱۵ دقیقه)
هیچ ضربه‌ای ثبت نشده🔴 غایب (مگر مرخصی/تعطیلی ثبت باشد)
