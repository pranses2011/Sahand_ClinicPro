# کلیپ تبلیغاتی سامانه جامع مدیریت درمانگاه سهند

کلیپ ویدیویی فارسی برای تبلیغ **Sahand ClinicPro** در اینستاگرام (ریلز، استوری، پست) و سایر شبکه‌ها.

## فایل‌ها

| فایل | کاربرد | مشخصات |
|:--|:--|:--|
| `sahand-clinicpro-promo-vertical.mp4` | ریلز، استوری، تیک‌تاک، یوتیوب شورتس | ۱۰۸۰×۱۹۲۰ · ۳۰fps · ۵۷ ثانیه |
| `sahand-clinicpro-promo-square.mp4` | پست فید اینستاگرام، لینکدین | ۱۰۸۰×۱۰۸۰ · ۳۰fps · ۵۷ ثانیه |
| `sahand-clinicpro-cover.jpg` | کاور/تامبنیل نسخهٔ عمودی (فریم پایان) | ۱۰۸۰×۱۹۲۰ |
| `sahand-clinicpro-cover-square.jpg` | کاور نسخهٔ مربع | ۱۰۸۰×۱۰۸۰ |
| `instagram-caption.txt` | متن و هشتگ‌های پیشنهادی پست | — |
| `build_promo.py` | سازندهٔ کلیپ (قابل اجرای مجدد و ویرایش) | Python 3 + Pillow + FFmpeg |

صدا: گفتار فارسی (گویندهٔ زن) + پد موسیقی آرام ساختهٔ موتور داخلی اسکریپت (بدون نمونهٔ بیرونی و بدون مسئلهٔ کپی‌رایت).

## ساخت مجدد / سفارشی‌سازی

```bash
pip install pillow numpy arabic-reshaper python-bidi imageio-ffmpeg
python3 build_promo.py                     # هر دو نسخه
python3 build_promo.py --format vertical   # فقط ریلز
python3 build_promo.py --stills 5,22,47    # چند فریم نمونه برای بازبینی
python3 build_promo.py --tempo 1.3         # سرعت گفتار تندتر
```

نکته‌ها برای ویرایش:
- متن‌ها و ترتیب صحنه‌ها در تابع‌های `scene_hook`، `scene_brand`، `scene_feature` و `scene_cta` تعریف شده‌اند.
- اندازه‌ها و فاصله‌ها در دیکشنری `LAYOUTS` (کلیدهای `vertical` و `square`).
- رنگ‌ها در دیکشنری `C` (هم‌راستا با لوگو و پوسترهای برند در پوشهٔ `docs/marketing`).
- تصاویر نرم‌افزار به‌صورت خودکار از `docs/screenshots` خوانده می‌شوند؛ با به‌روزرسانی اسکرین‌شات‌ها کلیپ هم به‌روز می‌شود.
- فایل‌های گفتار در `/tmp/vo/s1..s7.mp3` هستند؛ با جای‌گذاری فایل‌های تازه با همین نام‌ها و حذف کش `*.wav` در `/tmp/sahand_promo`، صدای جدید در کلیپ استفاده می‌شود.

## پیشنهاد انتشار در اینستاگرام

- کاور (Thumbnail): فریم پایان کلیپ (لوگو + «همین امروز شروع کنید»).
- متن پیشنهادی پست در فایل `instagram-caption.txt`.
- نسخهٔ عمودی را به‌صورت Reel و نسخهٔ مربع را به‌صورت پست فید منتشر کنید؛ در ریلز، زیرنویس فارسی (auto-caption) را فعال کنید.

# لوگوموشن (Logo Motion)

انیمیشن حرفه‌ای لوگو برای ابتدا/انتهای ویدیوها، ریلز و استوری.

| فایل | کاربرد | مشخصات |
|:--|:--|:--|
| `logo-motion-square.mp4` | پست فید، ابتدای ویدیو، ارائه | ۱۰۸۰×۱۰۸۰ · ۶۰fps · ۶.۸ ثانیه · با صدا |
| `logo-motion-vertical.mp4` | ریلز/استوری (اینترو یا اوتِرو) | ۱۰۸۰×۱۹۲۰ · ۶۰fps · ۶.۸ ثانیه · با صدا |
| `logo-motion-alpha.webm` | هم‌گذاری روی هر ویدیو در تدوین (OBS، DaVinci، وب) | ۱۰۸۰×۱۰۸۰ · ۳۰fps · VP9 با کانال آلفا |
| `build_logo_motion.py` | سازندهٔ انیمیشن (قابل ویرایش کامل زمان‌بندی/رنگ/متن) | Python 3 + Pillow + FFmpeg |

| ۰.۶۸–۱.۸ | فرود فنری لوگو با چرخش ملایم، فلاش و حلقهٔ نور | ضربهٔ نرم (Thump) |

## استفاده و بازسازی

```bash
python3 build_logo_motion.py                 # هر سه خروجی
python3 build_logo_motion.py --only square   # فقط نسخهٔ مربع
python3 build_logo_motion.py --only alpha --alpha-format mov   # نسخهٔ QuickTime (ProRes 4444)
python3 build_logo_motion.py --stills 0.9,2.4,5   # چند فریم نمونه
```

- نسخهٔ آلفا (`--alpha-format mov`) برای پریمیر/افترافکت است و حجم بیشتری دارد (~۷۰MB)؛ نسخهٔ WebM همان انیمیشن با آلفا و حجم ~۱MB است.
- زمان‌بندی‌ها در بالای فایل (`T_BADGE`، `T_TITLE`، `T_SHINE`، …)، رنگ‌ها در دیکشنری `C` و چیدمان در `LAYOUTS` قابل تغییر است.
- برای ساختن نسخهٔ ۴K کافی است `W`/`H` را در `LAYOUTS` بزرگ‌تر کنید (مثلاً ۱۸۰۰×۱۸۰۰).
