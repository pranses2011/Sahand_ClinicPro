🎯 اصول امنیتی پروژه: ClinicPro بر اساس استاندارد HIPAA و Defense in Depth طراحی شده. امنیت در همه لایه‌ها (Presentation، API، Application، Database) اعمال می‌شود و از اصل Zero Trust پیروی می‌کند: هیچ درخواستی بدون اعتبارسنجی قبول نمی‌شود.

🛡️ ۱۴ لایه امنیتی اصلی

🔐

۱. Password Hashing

همه رمزهای عبور با BCrypt (Work Factor=12) هش می‌شوند. هیچ رمز plain text ذخیره نمی‌شود. Salt منحصر به فرد برای هر کاربر.

BCrypt.HashPassword(password, 12);
🎫

۲. JWT Authentication

Access Token: ۱۵ دقیقه اعتبار | Refresh Token: ۷ روز با Rotation | امضا با HMAC-SHA256

[Authorize] public IActionResult Secure(){...}
🔄

۳. Refresh Token Rotation

با هر بار استفاده از Refresh Token، توکن جدید صادر و قدیمی باطل می‌شود. تشخیص سوءاستفاده از توکن سرقت‌شده و قطع تمام نشست‌ها.

👤

۴. RBAC (Role-Based Access Control)

سیستم ۳ سطحی: User → Role → Permission. دسترسی گرانولار به هر Module و Action. قابل تعریف در Runtime.

[HasPermission("Patients.Delete")]
🔒

۵. HTTPS/TLS اجباری

همه ارتباطات با TLS 1.3. HTTP → HTTPS Redirect خودکار. HSTS Header فعال. Certificate Pinning در کلاینت.

💉

۶. SQL Injection Prevention

استفاده از EF Core Parameterized Queries. هرگز String Concatenation. Input Validation در سطح DTO با FluentValidation.

// ❌ db.Query($"SELECT * FROM Users WHERE Id={id}"); // ✅ db.Users.Where(u => u.Id == id);
✅

۷. Input Validation

FluentValidation در Application Layer. XSS Prevention با HTML Encoding. فیلترینگ کاراکترهای خطرناک. طول و فرمت در همه فیلدها.

⚡

۸. Rate Limiting

5 Login/دقیقه برای هر IP. 100 Request/دقیقه برای کاربر عادی. 1000 Request/دقیقه برای Admin. با AspNetCoreRateLimit.

📋

۹. Audit Log جامع

ثبت همه عملیات CUD (Create/Update/Delete) + View‌های حساس. ذخیره IP، UserAgent، OldValues/NewValues (JSON). غیرقابل حذف.

🔐

۱۰. Data Encryption at Rest

داده‌های حساس بیماران (SSN, Phone, Address, Medical Records) با AES-256-GCM رمزنگاری. کلیدها در Azure Key Vault یا DPAPI.

var encrypted = aes.Encrypt(sensitiveData, key);
💾

۱۱. Automatic Backup

بکاپ خودکار روزانه (ساعت ۳ صبح). Transaction Log Backup هر ساعت. ذخیره محلی + Cloud. رمزنگاری فایل بکاپ.

⚖️

۱۲. HIPAA Compliance

رعایت استانداردهای حفظ حریم بیماران: Access Control، Audit Trails، Encryption، Data Integrity، Transmission Security.

⏱️

۱۳. Session Timeout

Idle Timeout: ۲۰ دقیقه | Absolute Timeout: ۸ ساعت | Auto-lock Screen در WPF Client. نمایش هشدار ۲ دقیقه قبل.

🔒

۱۴. Account Lockout

بعد از ۵ تلاش ناموفق: قفل اکانت به مدت ۳۰ دقیقه. اعلام به مدیر. ارسال SMS به کاربر در صورت فعال بودن 2FA.

✅ موارد اجباری

  • همه رمزها BCrypt هش شده‌اند
  • HTTPS فعال و HTTP ریدایرکت می‌شود
  • JWT با کلید قوی (256-bit)
  • Audit Log فعال است
  • بکاپ خودکار تنظیم شده
  • Rate Limiting روی API فعال
  • Firewall قوانین مشخص دارد
  • همه کاربران تست پاک شده‌اند
  • Secrets در Environment Variables هستند
  • appsettings.Production.json بررسی شده
  • Error Pages اطلاعات حساس نشان نمی‌دهند
  • CORS فقط برای دامنه مجاز فعال است

⚠️ موارد توصیه‌شده

  • Penetration Testing انجام شود
  • Security Scan (OWASP ZAP) اجرا شود
  • Code Review کامل انجام شود
  • Dependencies به‌روز باشند
  • Log Monitoring (Seq/ELK) راه‌اندازی
  • Health Check Endpoints فعال
  • SSL Certificate از CA معتبر
  • Database در Private Subnet
  • DR Plan (Disaster Recovery) تهیه شود
  • Incident Response Plan آماده
