🔄 الگوی ارتباط با سیستم‌های خارجی

همه سرویس‌های خارجی از طریق Service Interface و Dependency Injection پیاده‌سازی می‌شوند:

  • Pattern: Adapter Pattern + Strategy Pattern
  • Retry Policy: Polly Library برای Retry/Circuit Breaker
  • Logging: همه فراخوانی‌ها در ApiCallLogs ثبت می‌شوند
  • Caching: پاسخ‌های تکراری (مثل لیست داروها) کش می‌شوند
  • Async/Await: همه فراخوانی‌ها غیرهمزمان
  • Timeout: 30 ثانیه با قابلیت تنظیم
