Sahand ClinicPro v{VERSION} — راهنمای نصب نسخه درمانگاه

۱) نصب سرور (رایانه مرکزی درمانگاه)
- SQL Server 2019 یا جدیدتر باید نصب و روشن باشد.
- ZIP SahandClinicPro-Server-v{VERSION}.zip را استخراج و Install-Server-Package.bat را با Run as administrator اجرا کنید.
- رشته اتصال SQL Server را وارد کنید. نصاب بهصورت خودکار لاگین همان حساب را میسازد/شناسایی کرده و نقش سروری dbcreator را به آن میدهد تا ساخت دیتابیس و بازیابی فایل پشتیبان (RESTORE DATABASE) بدون دخالت دستی در SSMS انجام شود؛ نتیجه در restore-permission.status.txt ثبت میشود.
- نصب‌کننده یک کلید JWT تصادفی و قوی ایجاد می‌کند، دیتابیس را برای اولین بار می‌سازد، تمام تغییرهای schema را خودکار اعمال می‌کند و سپس API را به‌صورت Windows Service نصب می‌کند.
- اجرای dotnet-ef، نصب .NET SDK یا migration دستی لازم نیست. نصب اولیه ممکن است چند دقیقه طول بکشد.
- سرویس از پورت TCP 5000 استفاده می‌کند. برای شبکه درمانگاه، Windows Firewall rule نصب می‌شود.

۲) نصب کلاینت
- SahandClinicPro-Setup-v{VERSION}.exe را روی رایانه‌های موردنیاز اجرا کنید.
- اگر کلاینت روی رایانه دیگری است، فایل appsettings.json کنار برنامه را با نشانی سرور تغییر دهید:
  ApiSettings:BaseUrl = http://IP-سرور:5000/api/v1
  سپس برنامه را دوباره اجرا کنید.
- در همان رایانه سرور، مقدار پیش‌فرض localhost:5000 مناسب است.

۳) بررسی نصب
- روی سرور http://localhost:5000/health/ready باید status برابر Healthy نشان دهد.
- اگر نصب متوقف شد، رشته اتصال و دسترسی CREATE DATABASE را بررسی کنید؛ لاگ API در C:\SahandClinicPro\Server\Logs قرار دارد.

نکته مهم: از دیتابیس پیش از ارتقای نسخه پشتیبان بگیرید. نصب‌کننده فایل‌های برنامه را به‌روز می‌کند اما دیتابیس را حذف نمی‌کند.
